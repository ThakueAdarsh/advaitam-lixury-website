# Advaitam Luxury Destinations

A responsive React + Vite recreation inspired by the supplied Advaitam reference image.

## Run
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Included
- Responsive desktop/tablet/mobile layout
- Hero section with navigation
- Philosophy section
- Project carousel
- Lifestyle gallery
- Destination section
- Book-a-site-visit modal form
- CTA and footer
- Smooth scrolling and mobile navigation

## Images
The demo uses remotely hosted Unsplash image URLs so the ZIP stays lightweight. Replace the URLs in `src/main.jsx` with your licensed/local project images for production.
